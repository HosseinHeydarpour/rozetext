# Caption rewrite

The on-screen text is copied exactly. The caption is not. It is packaging for the same text, written in the page's voice and searchable.

## Voice

From the page's own top reels:

- Colloquial Persian, not formal literary prose.
- First person (`من`) or direct address (`تو`, `خودت`).
- Short sentences. One idea per sentence.
- A turn at the end: the line that makes someone send it.
- No fake depth, no advice-column tone, no "در دنیای امروز".

## Structure

1. **Opening line:** the core phrase, stated plainly. It should contain the word someone would search for (`آدم امن`, `مرز`, `دلتنگی`, `خداحافظی`).
2. **One or two lines:** the emotional turn, taken from the text's meaning.
3. **CTA:** one ask, not three.
4. **Hashtags:** one topical tag at most, then `#رزتکست` at the very end.

The whole caption is usually 1-3 short sentences. The text itself lives on the reel; the caption does not repeat it.

## CTA

Prefer a send:

- `بفرست برای کسی که...`
- `این را برای ... بفرست`
- `برای ... بفرست`

A save is second choice and only for a list or a quote worth keeping:

- `سیو کن برای روزی که...`

Never use `این را سیو کن` as the default. In the page's own data, send-CTA posts had a median of 233K views against 115K without, while save-CTA posts sat at 84K against 146K.

## Hashtags

- One topical tag from the theme: `#مرز`, `#عشق`, `#آرامش`, `#دلتنگی`, `#خداحافظی`, `#آدم_امن`, `#کارما`, `#مادر`.
- Then `#رزتکست` at the very end.
- Two tags maximum.
- Never `#روزتکست`.
- If the source caption has its own hashtags, drop them. Only the page's two remain.

## SEO

Instagram search reads the caption. Put the phrase people search for in the first line, in the same words they use. One tag reinforces it. No keyword stuffing.

Examples of the phrase in the data: `آدم امن`, `مرز`, `دلتنگی`, `خداحافظی باوقار`, `سنگ صبور`, `قدر`, `شعور`.

## If the source caption is empty

Write one from the on-screen text and the theme:

1. Take the strongest line of the text.
2. State it in one sentence.
3. Add the turn.
4. Add the send CTA and the two tags.

Mark `caption_origin: "generated"`.

## If the source caption exists

A light rewrite is enough:

- Keep the meaning.
- Change the opening so it is not a copy.
- Cut the source's hashtags and CTA.
- Add the page's CTA and tags.

Mark `caption_origin: "rewritten"`.

## Never

- Add a fact, name, number, date or quote that is not in the source.
- Change what the text says.
- Copy the source caption word for word.
- Use more than two hashtags.
- Use an em dash.
- Write a paragraph. The caption is short.

## Examples

Good, from the page's top reels:

- `بفرست برای خواهرت ❤️` (2.6M views)
- `و آخرین پیام من به تو🥀🖤` (2.4M)
- `آدم امن یعنی کسی که کنارت نقاب نمی‌زنه؛ می‌تونی پیشش بلند بخندی، گریه کنی و نگران قضاوت شدن نباشی. درست مثل تو...` (1.9M)

Weak, from the page's low reels:

- `شعور یعنی همین؛ کمتر سرک کشیدن تو زندگی بقیه. این را سیو کن. #شعور #رزتکست` (4K)
- `شب چاوشی پلی نکنید. این را سیو کن. #شب #رزتکست` (5.5K)

The weak ones are short, generic and ask for a save. The strong ones have a turn and ask to send.
